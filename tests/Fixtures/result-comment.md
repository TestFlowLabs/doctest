# Result Comment Assertions

## Integer

```php
$x = 42; // => 42
```

## Boolean

```php
$a = true; // => true
$b = false; // => false
```

## Null

```php
$n = null; // => NULL
```

## Multiple in one block

```php
$x = 1; // => 1
$y = 2; // => 2
$z = $x + $y; // => 3
```

## Mixed with output assertion

```php
$x = 42; // => 42
echo $x;
```
