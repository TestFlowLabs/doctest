# Basic Test

Simple PHP blocks with Output assertions.

```php
echo "Hello, World!";
// Output: Hello, World!
```

Some text between blocks.

```php
$x = 42;
echo $x;
// Output: 42
```

Block with no assertions (smoke test):

```php
$y = 100;
```

Multi-line output:

```php
echo "line1\n";
echo "line2\n";
echo "line3";
// Output:
// line1
// line2
// line3
```
