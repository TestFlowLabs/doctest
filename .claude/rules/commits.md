# Commit Rules

## Workflow

Always use the `agentic-commits` skill when creating commits. Never commit without invoking this skill first.

## No AI Attribution

Commit messages and content must never contain any AI/Claude attribution or traces:
- No `Co-Authored-By: Claude` or similar
- No `Generated by AI` or `Generated with Claude Code`
- No references to AI assistance in commit messages, PR descriptions, or code comments

## Never Push

Never push to remote automatically. The user will handle all pushes manually.
